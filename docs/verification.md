- 规则测试：未知字段及大整数保留、跨账号隔离、副号预算、禁用任务、类型/范围、启动任务排序、排班受保护字段。

- 模拟 Telegram 和 QQ：真实 HTTP 消息结构、文本消息段、事件去重、送达回执、未知结果不自动重发、显式重试、密钥加密和清除。
- 通知 Agent 不能改写固定事实；模型越界或失败时退回模板。日志监听不会把通用 SUCCESS、进程退出或历史记录当成新队列完成。

## 当前限制

- 实际挂机任务启动 / 停止、截图、额外自动调度与自动搓玉切换未启用。配置同步通过 v0.2 单独的逐次审批流程进行，详见 [Agent 模式](agent-mode.md)。
- 库存目标可读；现有共享仓库 / Box 缓存尚未确认账号归属，当前库存保持未知。
- MAA 进程存在只能证明进程存在；没有官方任务心跳时显示 unknown，而非 running。
- 生产日志仅是实例级文件尾，不假定每行都属于当前展示账号。
- 多用户权限、挂机任务互斥锁与额外调度器属于后续阶段；配置写入已有实例锁和受控备份回滚。
- Agent 当前适配的是已观察到的 6.20 新 GUI 配置。其他结构拒绝推断，不写入原件。
- HTTPS 初始使用本机生成的私有 CA。浏览器需明确安装公有 CA 证书或改用用户自己的受信任证书。
