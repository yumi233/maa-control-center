# 通知

## 公招五星、六星独立特别提醒（v0.5.5）

升级 Windows Agent 和 NAS 服务后默认跟随账号已有的启用通知渠道，无需创建新定时。主号仍只发原 TG，限定副号的 QQ 群仅收到副号记录。

- `RecruitResult.details.level` 为最佳组合的最低星级。5 触发五星机会；`高级资深干员` 触发六星机会，包括被原保留标签规则跳过的情况。
- 单独醒目标题、识别时间、全部标签和保底组合，不依赖 AI 文案，不等待队列结束。它是标签机会，不能当作已经获得干员。MAA 未提供可靠的出货干员回执时不会猜测实际出货。
- 不改选标签、招募时长、刷新、加急或预算；仍由原公招配置决定下一步。
- 原执行记录绑定账号与配置档；无法确认归属不广播。事件与 outbox 原子保存，重复心跳、日志轮转、服务器重启不重复发送。首次升级不扫描升级之前的标签历史。
- 没有槽位字段时不虚构槽位。相同执行轮次、同一个公招任务、相同完整标签集合按一个机会去重。

## Telegram 受控出口

仅服务器管理员通过环境变量或私有字符串配置 `MAACC_TELEGRAM_PROXY` 指定 `http://IP:port` 或 `https://IP:port`。不允许含账号、密码、查询参数、路径或 DNS 主机名；私有文件不得提交 Git。

该客户端只接受 `https://api.telegram.org:443`，依旧验证官方证书、禁止重定向；不改变其他模型或 QQ 通知的 DNS/IP 防护。不使用环境自动代理，也不会把用户可填地址变成通用代理。用于透明网关 fake-IP 导致 TG 直连失败的场景。配置为空保持原直连模式。

失败消息须核实未发送才重试，unknown 仍需人工核实。切换出口不会自动重放历史通知、重跑游戏或补跑过期计划。
