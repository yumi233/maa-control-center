# Cloudflare Tunnel

使用独立的 MAA 隧道和容器，将一个明确的域名路由到控制中心的 HTTPS 端口。无需更改现有网站隧道、开放路由器入站端口或关闭 NAS 端证书验证。

源站为私有 CA 签发证书时，在 `originRequest.caPool` 指定挂载的 CA 公共证书，保持证书验证开启。不要使用 `noTLSVerify`。隧道管理证书及运行凭据存放在私有目录；运行容器只挂载自己的配置、凭据和源站 CA，不挂载管理证书或整个项目密钥目录。

服务端 `MAACC_PUBLIC_URL` 设置为公开 HTTPS 域名。若同时从局域网登录，在 `MAACC_ALLOWED_ORIGINS` 中加入确切的局域网 HTTPS Origin，以逗号分隔，最多八项。不能填写通配符或路径；不依据请求中的转发 Host 自动放宽来源。所有写请求仍需要当前登录的 CSRF 凭证。

隧道配置末尾使用 `http_status:404` 兜底，其他域名不路由到 MAA。容器使用重启策略、只读文件系统、独立挂载、有效 DNS 和日志限额。公开访问仍须登录，未登录只能访问静态网页和健康检查。不要把用户密码、Bot Token 或隧道凭据提交到仓库。
