# 验证记录与限制

## 已在开发机运行

- Vue / TypeScript 类型检查与 Vite 生产构建。
- Linux amd64 NAS 服务、Linux 初始化程序、Windows amd64 Agent 交叉编译。
- Go 测试：登录与 Cookie 保护、匿名 API 拒绝、CSRF、来源校验、只读控制拒绝、Agent 配对、心跳时效、双配置档隔离、资源预算预览、幂等键唯一性、重启时 unknown 恢复。
- Agent 测试：独立基建文件、未知扩展字段保留、原件不变、目录边界、损坏 JSON、大小限制、日志过滤。
- 官方远程控制 Mock：稳定任务 ID、SUCCESS 不等于游戏成功、停止确认语义、心跳、危险任务类型拒绝。

Go 竞态检查与静态检查已通过。浏览器已验证 1440px 桌面和 390px 手机浅深两套主题、任务添加、库存搜索；390px 页面实际宽度为 390px，无横向溢出。真实部署的最终结果将在验收后追加。Mock 与单元测试不代表真实挂机任务已经执行成功。

## 当前限制

- v0.1 是能连接真实 Agent 的只读 MVP。实际任务启动 / 停止、截图、配置同步、自动调度、策略应用与搓玉切换没有启用。
- 库存目标可读；现有共享仓库 / Box 缓存尚未确认账号归属，当前库存保持未知。
- MAA 进程存在只能证明进程存在；没有官方任务心跳时显示 unknown，而非 running。
- 生产日志仅是实例级文件尾，不假定每行都属于当前展示账号。
- 多用户权限、生产任务互斥锁、完整调度器和配置版本回滚属于后续阶段；数据库结构预留不等于实现完成。
- Agent 当前适配的是已观察到的 6.20 新 GUI 配置。其他结构拒绝推断，不写入原件。
- HTTPS 初始使用本机生成的私有 CA。浏览器需明确安装公有 CA 证书或改用用户自己的受信任证书。
