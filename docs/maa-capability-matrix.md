# MAA 能力矩阵（v0.5.0）

以当前代码、对应回归和部署证据为准。模拟测试、已有真实任务记录、生产只读核对与新一轮真实游戏执行分别记录，不互相替代。

| 能力 | 当前行为 | 边界 |
| --- | --- | --- |
| 多用户与改密 | 用户隔离、自助改密、管理员分配账号 | 不修改现有密码，停用用户后禁止访问 |
| 配置、库存目标与排班编辑 | 已核实 MAA 6.20 字段预览、确认、备份、写入、重读与回滚 | 未列字段拒绝；库存实时数量不能从无归属缓存推断 |
| 多账号任务与定时 | 日/周计划、实例串行、原生入口、停止回执、未知结果核实 | Agent 执行白名单需包含实际配置档；不能把配置切换检查当游戏验收 |
| 开始与结束通知 | 每任务开始一次；完成、失败或确认停止后汇报 | 队列回执与日志事件共用去重；未知送达不自动重发 |
| 理智与今日汇报 | 实际读数带观察时间、本次任务/结算/掉落、北京时间当日同账号汇总 | 结束时不额外打开游戏实测；日志完整且之后无作战时才显示自然恢复估算 |
| TG / AstrBot / OneBot | 渠道回执、账号范围、独立测试、加密密钥 | 受对应平台权限与网络限制；sent 不代表已阅读 |
| 群控与成员 | 状态、开始/停止、汇报、今日、计划；UID 角色、撤销、移交保护 | 无任意脚本、预算改动、提权或定时写入；真实群入站需成员发指令确认 |
| OpenAI 兼容配置助手 | 明确型号、结构化方案、规则验证与确认 | 兼容性回归使用模拟服务；真实模型测试需用户已配置接口，不为开发验收产生付费调用 |
| 自动搓玉 | 展示条件与未实现状态 | **未实现自动执行与安全恢复** |
| 自动制造配方切换 | 展示现有 product 配置 | **未实现自动切换及游戏结果验证** |
| 原生远程协议旧入口 | 保留协议 Mock 与受保护的历史入口 | 不等同于本项目当前 Windows 原生窗口队列；不以协议受理证明游戏成功 |

新账号、成员加入、通知与移交见 [群控方案](group-control.md)；任务执行见 [配置与定时](configuration-and-scheduling.md)；通知的理智来源与去重见 [Agent 模式](agent-mode.md)。
