# 现有配置保护与备份

本版本不提供对 MAA 文件的写入接口，也不会改动其定时器、药剂预算或基建分工。

部署前后，使用源文件原始字节计算 SHA-256，至少涵盖：

- `config/gui.json`
- `config/gui.new.json`
- 每个配置档实际引用的基建 JSON

调查确认的配置原件与哈希清单应复制到 Windows 新项目目录下的私有备份子目录。保持原目录原样，禁止将这些文件提交至公开仓库。

Agent 展示的配置哈希来自原始字节。JSON 中不认识的排班扩展字段保留在只读快照中。损坏、正在变化或超出大小限制的文件不导入，不用空配置覆盖原文件。

Web 数据库使用 SQLite WAL。备份应使用 SQLite backup API，例如 `scripts/backup.sh`，不要只复制运行中的 `.db` 而遗漏 WAL。恢复时停止本项目的服务，在新目录验证备份完整性后再启动。Windows MAA 原件不参与 Web 数据库恢复。

任何未来的生产配置同步都必须另行实现原子替换、版本冲突、备份回滚、安全重载，并验证 MAA 退出时的回写行为。v0.1 没有把这些未完成能力包装成可用功能。
